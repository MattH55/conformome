# Conformome

An open, per-protein index of every technique that has probed a protein's conformation, organised around a shared layer of conformational states and transitions. Each page is keyed on a UniProt accession. Each state and model is labelled **observed** (directly resolved by X-ray, cryo-EM, microED, neutron or NMR structure) or **inferred** (fitted to indirect constraints), and inferred states list their assumptions.

The site is built from this repository and deployed to conformome.org. Every number on it is regenerated by `make`.

**Status: pilot.** 81 proteins, with evidence from RCSB PDB, BMRB, SASBDB, DisProt, AlphaFold DB, MDDB and SMASH-BIO. 30 have draft curation (states and mappings) that no curator has reviewed yet; the other 51 have evidence-only pages until someone curates them. See [docs/PILOT_REPORT.md](docs/PILOT_REPORT.md). Picking this up? Start with [docs/HANDOFF.md](docs/HANDOFF.md).

## Use

Python 3.11 or newer.

```sh
pip install -e ".[test]"
make download        # fetch raw inputs (needs network); writes data/MANIFEST.json
make site            # ingest -> map -> models -> static site in site/dist/
make validate        # site, schema, reference, licence and link checks, plus tests
```

Limit a step to some proteins with `ACC="P69441 P0DP23"`.

## Layout

| Path | Contents |
|---|---|
| `conformome/` | Pipeline package: `sources/` (one module per source), `mapping/`, `models/`, `site/`, `validate.py` |
| `schema/` | JSON Schemas for protein, state, evidence, transition, model and shared definitions |
| `taxonomy/techniques.yaml` | Each technique, its basis (observed or inferred), whether it is a prediction, and its observables |
| `targets.yaml` | Every protein the site builds, with the batch (reason) it was added in |
| `curation/` | One YAML per curated protein: states, assignments, rules, transitions (see `curation/README.md`) |
| `data/` | `MANIFEST.json` committed; raw downloads are git-ignored |
| `tests/` | Unit tests, a real GraphQL response as parser input, and a synthetic fixture protein with expected outputs |
| `docs/` | `HANDOFF.md`, `METHODS.md`, `SOURCES.md` (licences), `CONTRIBUTING.md`, `PILOT_REPORT.md` |

## Deployment

The site is published with GitHub Pages. On every push to the default branch, `.github/workflows/deploy.yml` downloads the raw inputs, runs `make validate`, and deploys `site/dist/`. It can also be run by hand from the Actions tab (workflow_dispatch).

- Pages must be set to deploy from **GitHub Actions** (repository Settings → Pages → Source). The workflow tries to enable this itself; if the token is not allowed to, set it once by hand.
- Until a custom domain is set, the site is at `https://matth55.github.io/conformome/`. All links are relative, so it works at that path.
- For conformome.org: add the domain under Settings → Pages → Custom domain, then follow GitHub's instructions for the apex A records and the `www` CNAME at the registrar, and enable HTTPS. `site/dist/CNAME` already names the domain.
